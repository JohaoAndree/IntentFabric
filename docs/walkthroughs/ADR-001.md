# Walkthrough — ADR-001

Se implementó la Parte B de ADR-001 en la rama
`adr-001/estructura-hexagonal`, incluida la corrección P2 del commit `a955802`.

## Cambios

- Cinco paquetes bajo `src/intentfabric/`: `domain`, `application`,
  `services`, `vendors` y `adapters`, con inicializadores que contienen
  únicamente su docstring.
- `bootstrap.py` reservado como raíz de composición, solo con docstring.
- Analizador estático en `tests/unit/test_architecture.py` para verificar
  dependencias entre capas, terceros permitidos y aislamiento de plugins.
- Resolución de imports absolutos y relativos, incluidos los de
  `TYPE_CHECKING` y la forma `from X import a`.
- Corrección P2: rechazo de módulos raíz no reservados, incluso cuando
  tienen nombres de capas; los paquetes correspondientes siguen válidos.
- README actualizado y evidencia registrada en la sección 10 del ADR.

## Verificación

Entorno: Windows y Python 3.14.2 en `.venv`.

- `python -m pytest -q`: 97 pruebas aprobadas, incluidas las 11 previas
  de ADR-002.
- Cobertura de 49 combinaciones de capas, violaciones sintéticas,
  análisis sin ejecución y diagnósticos deterministas.
- Import prohibido temporal en `domain/`: fallo detectado y archivo
  restaurado sin cambios residuales.
- Regresión P2 contra el analizador de `4f1cc62`, en un directorio temporal
  externo: cinco fallos esperados; `utils.py` ya se rechazaba correctamente.
- Tras la corrección, los seis casos pasan y el árbol queda limpio.
